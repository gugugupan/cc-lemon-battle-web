## 1. 一句话介绍

以手游戏「CCレモン」为原型的节奏对战网页游戏：每小节 4 拍，在第 4 拍「ケン / 拳」出招（攻击 / 防御 / 蓄力 / 必杀技），和性格各异的对手猜拳式结算。
目标是连赢 20 场；每赢一场可以在小卖部买道具、开宝箱拿遗物，或者休息回血。通关后可以继续无尽模式。

- 技术：Vite + TypeScript + Three.js，DOM 做 HUD，Web Audio 做节拍和全部声音，vitest 测试。
- 语言：日文 / 简体中文（标题画面切换，`src/i18n.ts`）。
- 仓库：`~/workspace/fde/cc-lemon-web`，直接提交到 `main`，远端 `gugugupan/cc-lemon-battle-web`。

## 2. 运行与开发

```bash
npm install
npm run dev        # http://localhost:5188 （BGM 试听页：/bgm.html）
npm test           # 单元测试 + 单场难度曲线
npm run sim:runs   # 每个角色连打 20 场的整局模拟
npm run sim:builds # 随机遗物组合的强度报告（装备叠加）
npm run build      # 静态网站输出到 dist/
```

开发模式下浏览器控制台里有 `window.app`，可以直接改状态做测试，例如：

- `app.battle.enemy.hp = 1`：下一次命中就赢。
- `app.run.round = 20`：进入第 20 场，打赢就通关。
- `app.run.relics.push(...)`：给自己加遗物（对象格式见 `src/core/items.ts`）。

在浏览器里测试会写入 localStorage（纪录、通关、购买记录），测完记得还原（见第 11 节）。

## 3. 战斗规则

### 3.1 节拍与判定

- 时钟以 `AudioContext.currentTime` 为准（`src/audio/clock.ts`），不看帧时间；每拍在音频线程上提前排程。
- 按键时间用 `event.timeStamp` 回推到按下的那一刻，再扣掉输出延迟和「节拍校准」测出的补偿值。
- 判定：PERFECT ±50 ms、GOOD ±110 ms、其余 MISS。MISS 也算有效出招（没有惩罚，只是拿不到 Perfect 加成）。
- 只在第 4 拍出招；第 1–3 拍按方向键无效。道具在第 1–3 拍使用，每拍最多一个。

### 3.2 小节

- 开场的第 0 小节是预备拍。
- 默认**没有结算小节**：出招后直接进入下一小节，回合在第 4 拍的半拍后结算（胜负、遗物效果）。
- 遗物「茶歇」会在每次出招后加一个 4 拍的结算小节（不能输入）。
- 什么都不按 = 观望：这一小节不结算，对手也不出手；连击清零，FEVER 结束。例外：带「😤 急性子」的对手照样出招，玩家当作什么都没做（被攻击扣 1、被必杀扣 2，对手蓄力照涨）；画面上只有对手的手势牌飞出。

### 3.3 招式与结算

| 招式 | 按键 | 能量 | 攻击 | 防御 |
|---|---|---|---|---|
| 攻击 | → | −1 | 1 | 0 |
| 防御 | ← | 0 | 0 | 1 |
| 蓄力 | ↓ | +1 | 0 | 0 |
| 必杀技 | ↑ | −3 | 2 | 0 |

- 能量上限默认 3；能量不够时出招是**挥空**（算 0/0，仍会被打）。
- 双方攻击力都 > 0 时**相杀**，只把差值打给弱的一方；否则各打「攻击 − 对方防御」。
- 结果：攻击打中蓄力；防御挡住攻击；必杀技破防（打防御扣 1、打蓄力扣 2）；攻击 vs 攻击抵消；必杀 vs 攻击，攻击方扣 1。
- 遗物可以改：伤害加成、防御额外挡住必杀（护腕 / 铁壁）、必杀技消耗（省力）、对手蓄力 +2（后期对手）、本小节免伤（盾牌贴纸）等。

### 3.4 破绽（读心）

- 对手每个出招小节的第 2 拍可能冒出气泡，提示它这回合要出什么；可能是假的。
- 出现率：第 1 场 50%，每场 −1.5%，最低 25%；乱拳型对手 ×1.4，读心型 ×0.8；观望时每小节减半。
- 准确率：80% → 最低 60%。说谎时只会挑对手付得起的招。
- 台词：每种招式 5 句，从直白到隐晦；第 1–2 场只用第 1 句，每 2 场多解锁 1 句，第 9 场起 5 句全用。
- 相关遗物：观察日记（出现率 ×1.5、准确率 +10%）、透视眼镜（每小节必出）、侦探帽（观望后下一小节必出）；敌人的扑克脸（准确率 −40%）、面具（完全不露）。

### 3.5 连击与 FEVER

- 连击 = 连续有出招的小节数（任何判定都算），观望清零。10 连击进入 FEVER，直到下一次观望。
- FEVER 本身没有数值加成，但很多道具 / 遗物在 FEVER 中更强；敌人有专门惩罚 FEVER 的遗物（灭火器、盯防、冷场等）。
- Perfect 连续数单独计算，给碳酸气泡、节拍器这类遗物用。

## 4. 一局游戏

- 目标：**连赢 20 场**。场次显示为「第 n / 20 战」，通关后进入无尽模式显示「第 n 战 ∞」。
- 每场胜利：得到 25 + 3n 金币（**不会自动回血**，HP 原样带到下一场）；强敌 ×2 并免费开一个宝箱。
- 普通胜利后有 35% 机会先遇到一个随机事件（`src/core/events.ts`，强敌战后不会出现）：
  | 事件 | 选项 |
  |---|---|
  | 🥤 自动贩卖机 | 买一瓶（15 金币，♥+2）／踢一脚（50% 得随机道具，否则 HP −1，最低 1）／离开 |
  | 🍬 零食店 | 买点东西（15 金币，随机道具，要有空格）／离开 |
  | 📒 遗落的作业 | 交给老师（+20 金币）／抄答案（随机遗物，HP −3，最低 1） |
  | 🛏️ 医务室 | 躺一会儿（♥+1）／拿创可贴（要有空格） |
  | 🌀 神秘转学生 | 接受挑战：下一场变成强敌（HP +2，第 10 场起 +3），赢了开免费宝箱、但金币不翻倍／离开（下一场本来就是强敌或 Boss 时不会出现） |
  | ⛩️ 神社 | 献上体力：最大 HP −1，开一个宝箱（最大 HP 至少 3 才能选）／离开 |
- 然后进入小卖部：
  - 货架：3 个消耗道具 + 1 个「宝箱」，外加固定的「休息」（6 金币 ♥+1，可重复买到满血；回血只能靠这里、道具、遗物和事件）。
  - 宝箱：每次光顾限 1 个，价格 = 45 ×（1 + 0.15 × 已持有遗物数），取整到 5（`CHEST_PRICE` / `CHEST_PRICE_STEP`）。打开后从 3 个还没有的遗物中**必须**选 1 个；不想要可以之后半价卖掉。
  - 开箱动画：宝箱摇晃 → 盖子弹开、光芒和气泡 → 3 张卡片依次飞出；点画面或按 Enter 可以跳过，按 1–3 选择。强敌奖励用同一个弹窗。
  - 遗物的 `price` 不再用于购买，只用来算卖出价（半价，最少 5）。
  - 已有的遗物和道具可以半价卖掉（最少 5 金币）。
  - 道具栏固定 4 格，点两个格子交换位置。
- 输了（含平局）就结束；纪录按角色保存。
- 打赢第 20 场：纸屑 + 金色天空 + 全场欢呼的庆祝动画，然后选择「就此结束」或「进入无尽模式」。通关时间记在 localStorage，标题画面显示金色的「已通关」徽章。

## 6. 敌人

### 6.1 成长（`enemyFor(n)`，`src/core/run.ts`）

| 项目 | 规则 |
|---|---|
| HP | 3 + ⌊(n−1)/5⌋，第 10–14 场 −1（上限 11）；强敌 +1（第 10 场起 +2） |
| BPM | 92 + 3(n−1)（上限 156）；强敌 +6 |
| 能量 | 上限 3，第 10 场起 4；开局 0 → 第 6 场 1 → 第 12 场 2 |
| 蓄力 | 第 15 场起每次蓄力 +2（蓄力型从第 1 场就是；`STRONG_CHARGE_FROM`） |
| 遗物 | 第 7 场起 1 个，之后每 5 场 +1，最多 6 个；强敌第 10 场起多 1 个；档位：1（全程）/ 2（第 6 场起）/ 3（第 10 场起） |
| 急性子 | 额外特性，不占遗物名额：第 6 场 30%，逐场增加，第 15 场起 100%（`impatientChance`） |
| AI | 攻击倾向 1.0 → 1.7；读招 0.3 → 1.3；随机性 0.35 → 0.05；谨慎度固定 |
| 强敌 | 第 5、10、15、20 场 |
| Boss | 第 20 场（无尽模式每 20 场）是「レモン仙人」：数值同该场强敌 +1 HP（之后每次 +1）、读心型大脑；HP 降到一半进入「本気モード」：拿出隐藏遗物（第一次 充电宝+铁壁，之后每次多一件：吸血牙、拳击手套）、BPM +15、AI 变激进。介绍卡只透露「??? ×n」。 |

### 6.2 性格（`PERSONALITY_TUNING`，`src/core/ai.ts`）

| 性格 | 打法 | 倍率要点 | 出现机率（前 / 中 / 后期） |
|---|---|---|---|
| 🔥 猛攻型 | 有能量就打 | 攻击 ×1.4、谨慎 ×0.5 | 35 / 25 / 20 |
| 🛡️ 稳守型 | 挡住后反击 | 谨慎 ×1.8、挡住后攻击 +1.6 | 15 / 20 / 20 |

开战介绍卡和 HUD 会显示性格和一句应对提示。

### 6.3 AI 规则（`decide`）

- 共用一套「按权重选招」的逻辑，性格只改参数。
- **硬性规则**：付不起的招不出；满能量不蓄力；**你没有能量时绝不防御**（随机出招也一样）；**你满能量时防御权重 ×2.5**。
- 会预测你的下一招（看你最近几次出招的接续）；打中你之后更爱继续进攻；稳守型挡住你后倾向反击。
- 进攻比例（2026-09-29 调整前实测）：第 1 场约 33%，第 8 场约 46%，第 15 场约 54%（必杀技约 15%）；之后蓄力 +2 推迟到第 10 场、攻击倾向上限降到 1.7，中期会略低一些。

## 8. 教程（`src/core/tutorial.ts`）

10 步，80 BPM，对手是按剧本出招的练习用稻草人：开场 → 看节拍 → 蓄力 → 攻击打中蓄力 → 看破绽并防御 → 先蓄力再用必杀技破防 → 观望一小节 → 第 1–3 拍用道具 → 实战（可重来）→ 结语。

- 对话时节拍暂停，Enter 推进；练习时只接受这一步允许的按键。
- 连续失败 3 次出现强提示，对应按钮闪烁。Esc 或右上角 ✕ 按两次退出。
- 仙人的对话框点一下（或 Enter）翻页；手机只能靠点对话框推进（2026-10-02 修复：之前只认 Enter，手机卡在第一句）。
- 完成后标题画面的教程按钮显示 ✓；没玩过时标题画面会提示先玩教程。
- 判定逻辑 `TutorialTracker` 是纯逻辑，有单元测试。

## 9. 界面与操作

| 场景 | 按键 | 作用 |
|---|---|---|
| 战斗 | → ← ↓ ↑ | 第 4 拍出招（手机点屏幕上的十字键） |
| 战斗 | 1–4 | 第 1–3 拍用道具（手机点道具格） |
| 选择 / 菜单 | ←→、Enter、Esc | 切换、确定、返回 |
| 商店 | 点击 | 买、卖、交换道具位置 |
| 教程 | Enter 或点对话框 / Esc 或 ✕ 两次 | 推进 / 退出 |

- 鼠标移到道具、遗物上显示效果和系列（手机上点遗物显示）。
- 战斗 HUD 按窗口大小等比缩放（以 1280×720 为 1 倍，0.8–1.8 倍；竖屏按宽度）。自己的信息卡在左下角道具格上方（窄屏时缩成一行：红心、能量、遗物），对手信息在右上；让玩家战斗时主要看画面下方。窄屏时回合数在左上、对手卡在右上。
- 节拍提示有两处：
  - 屏幕四边的光带（`.beat-frame`）：第 1–3 拍依次点亮上 → 右 → 下并保持，第 4 拍四边一起亮柠檬黄；FEVER 时变金色，结算小节变淡紫。
  - 十字键中间的节拍表：深色底 4 格，前 3 格依次亮薄荷绿，最后一格 🍋 在第 4 拍亮黄并弹一下。，第 3 拍时可用的按钮外圈发光，第 4 拍整个十字键闪一圈黄光。
- 破绽气泡：粗边框、弹出动画，固定在对手头顶，会自动挪进屏幕内（尾巴仍指向对手）。「様子見」是深色药丸提示。
- 对手介绍卡的头像是性格图标（🔥🛡️⚡🧠🎲）配对手颜色；选角圆点显示各角色的图标（未解锁显示 🔒）。
- 竖屏时标题、对手介绍、胜利等面板贴近底部，露出舞台上的角色。
- 商店：宝箱单独一行放在最上面，消耗品和休息在下一行。

## 10. 画面、模型、声音

- 舞台（`src/view/stage.ts`）：渐变天空、圆形舞台、舞台外圈在第 4 拍闪光（空中的节拍球已拿掉，节拍只看十字键中间的 4 个点），手势牌相撞、粒子、震屏、镜头推近；FEVER 时天空变金色。
- 公园场景（`src/view/scenery.ts`）：每场随机布置树、岩石、栅栏、旗子、自动贩卖机；3–5 个围观者（没上场的角色）跟着节拍晃动、结算时一起跳、欢呼或叹气；2–3 只小动物走走停停，FEVER 时跳舞。
- 模型：Kenney 的 Mini Characters / Mini Forest / Mini Arcade / Cube Pets（CC0，`public/models/`，许可文件在各文件夹）。
- 声音：全部由 Web Audio 合成。`src/audio/synth.ts` 是音效和每拍提示音；`src/audio/music.ts` 是 BGM：普通关卡按顺序轮流播放 3 首 Lo-fi（放学后 → 黄昏教室 → 汽水 Chill-hop），强敌关卡播放电子 Funk，都和判定时钟从同一拍开始、跟着对手 BPM 走，FEVER 时加一层。标题画面的「🔊 音量」可以分别调音乐和效果音（0–100%，默认 50%；效果音包含节拍提示音）；音乐调到 0 就是关掉，改用内建的节拍鼓组。所有候选风格可以在 `/bgm.html` 试听。

- 必杀技动画：放招方镜头推近（`Stage.focus`），HUD 弹出「必殺！」集中线插画（敌人是覆盆子红色调），0.12 秒后从放招者飞出一颗旋转的 3D 大柠檬（`Stage.lemonShot`），约 0.3 秒落地：命中时果汁爆开、闪白、强震屏（破防时对手的护盾先碎裂）；被挡下时柠檬弹开；双方相杀时两颗柠檬在中间对撞。被打的一方的伤害数字、血量更新等落地再出现。专属落地音效 `Synth.specialImpact`。

### 首屏加载
- `index.html` 内联了一个柠檬加载画面；`src/main.ts` 用动态 import 载入游戏本体，载完后淡出加载画面。
- `vite.config.ts` 用 rolldown 的 `advancedChunks` 把 three.js 拆成单独的 chunk（约 630KB / gzip 159KB），游戏代码更新时可以继续用缓存；入口只有约 2KB。

## 13. 测试与平衡工具

模拟器在 `src/core/sim.ts`，玩家用 `PlayerModel` 描述：
- `CASUAL`：老 bot（看情况乱出、只在低血量用创可贴），只用于单场难度曲线。
- `SKILLED`：读破绽、Perfect 85%、会用全部消耗道具（炸弹先扔、看到攻击破绽贴盾 / 暂停、差能量喝汽水……）、按遗物系列调整出招（连击系多攻、防守系多防、观望系多等、FEVER 系不观望）。
- 反应时间模型（`reaction` 0.7 秒）：破绽在第 2 拍出现，到第 4 拍出招只有 2 拍；BPM 越快越来不及反应，所以双倍速、快板的代价也算进去了。

命令：
- `npm test`：单元测试 + 单场难度曲线，外加**装备护栏**：熟练玩家拿随机 7 件遗物、7 HP、4 个随机道具打第 20 场，最强 5% 组合胜率不能超过 92%，任何一件遗物的边际强度不能超过 +15 个百分点（`tests/balance.test.ts` 的 `GUARD`）。改数值后护栏挂了 = 有东西超标。
- `npm run sim:builds`：第 10 / 15 / 20 场分别用 4 / 6 / 8 件随机遗物，打印胜率分布（最强 / 前 10% / 中位数 / 后 10%）、每件遗物的边际强度表和最强组合。
- `npm run sim:runs`：每个角色 300 局整局模拟，三列：普通 bot、熟练玩家随机挑遗物、熟练玩家按强度表挑遗物（强度表由 `sampleBuilds` 现算）。断言「熟练 + 挑最强」的平均通关率在 25–40%。

2026-10-02 平衡后（熟练 + 挑最强 / 熟练 + 随机挑）：

| 角色 | 挑最强 | 随机挑 |
|---|---|---|
| 普通同学 | 38% | 14% |
| 图书委员 | 34% | 9% |
| 棒球部 | 14% | 5% |
| 风纪委员 | 29% | 8% |
| 管乐部 | 35% | 14% |
| 推理社 | 28% | 10% |
| 必杀少年 | 16% | 5% |
| 神秘转学生 | 28% | 7% |

- 第 20 场、7 件遗物：中位数 63%，最强 5% 约 90%（平衡前 97%）。目前最强的单件是护腕（+14），其次碳酸气泡、省力、节拍器、透视眼镜（+6～7）。
- 模拟器的局限：bot 不会像真人那样摸清对手性格、也不会刻意打连攻，所以连击系（三连拳、终结技、不屈、追击）在模拟里偏弱，真人可能更强；真人整体也比 bot 强，实际通关率会高于表里的数。
- 教训：单场模拟看不出「HP 延续」造成的累积难度，调曲线一定要看整局模拟；只测「裸装」也看不出装备叠加的问题，一定要跑 `sim:builds` / 护栏。

## 14. 已确定的设计决定

- 第 4 拍出招，默认没有结算小节（茶歇遗物加回来）；观望不结算；MISS 没有惩罚。
- 敌人 = 名字 + 数值 + 遗物 + 性格，共用一套 AI；硬性规则见 6.3。
- 商店不偏向系列；道具栏固定 4 格，不卖属性提升，只有「休息」回血。
- 遗物只能从宝箱拿（每次光顾 1 个，越多越贵，必须三选一），避免后期把强遗物收齐。
- 20 场为阶段目标，之后可无尽；最高纪录按角色保存。
- 角色解锁有两种：胜场，或「买到 / 从宝箱拿到过某个道具」（强敌的免费宝箱也算）。
- 手机只在「点遗物」时显示说明，点道具格就是使用（不做长按，避免影响时机）。

- 没有做的：随机事件、成就、每日挑战、分角色通关标记。
